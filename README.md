# Pixel Art Semester Calendar

A single self-contained pixel-art calendar for the Year 3 Semester 1 dental-school
timetable, 1 September 2026 – 1 January 2027. Every class session, exam, re-sit,
course start/end, holiday and break from Draft 6 of the timetable.

**Open `index.html` by double-click.** No build step, no server, no network — it
works straight off disk with the network off. Light and dark themes follow your OS.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The finished calendar. Everything (data, styles, font, sprites, logic) is inlined. This is the only file you need. |
| `schedule.json` | The parsed timetable — the single source of truth the app reads. Regenerated by the parser. |
| `CONTRACT.md` | The frozen data contract: the exact shape of `schedule.json` and every parsing rule. |
| `STYLE.md` | The frozen visual contract: palette, grid, typography, component classes. |
| `src/parse_schedule.jl` · `parse_schedule.py` | Julia (primary) and Python twins. Read the vault notes, write a byte-identical `schedule.json`, print a reconciliation summary, exit non-zero if the totals don't match. |
| `src/build.jl` · `build.py` | Julia and Python twins. Inline `src/app.html` + `font.css` + `pixel.css` + `sprites.html` + `app.js` + `schedule.json` into `index.html`. |
| `src/app.html` · `app.js` · `pixel.css` · `font.css` · `sprites.html` · `sprites.svg` | The un-inlined sources, kept so the app stays maintainable. |
| `src/preview.html` | Design-system preview — every component and state, for judging the visuals. |
| `src/schedule.stub.json` | A small contract-valid stub used only when opening `src/app.html` directly during development. |
| `src/OFL.txt` | SIL Open Font Licence for the embedded Press Start 2P subset. |

## Updating it when the timetable changes

The source notes live in
`C:\Users\jorre\Documents\Cowork Sandbox\Cowork Vault\Schedule\`. When Draft 7
lands, or the Examinations Section confirms the Week 15/16 dates, edit those notes
and then, from `src/`:

```
julia parse_schedule.jl      # regenerates ../schedule.json (or: python parse_schedule.py)
julia build.jl               # re-inlines everything into ../index.html (or: python build.py)
```

The parser prints per-course counts and **exits non-zero if anything fails to
reconcile** — if that happens, fix the note (or the contract) before rebuilding. No
file is ever hand-edited. Personal dates (birthdays, anniversaries) go in an
optional `Personal Dates.md` in the vault, as a `| Date | Occasion |` table.

## Notes on the data

- The Week Index is authoritative for teaching sessions; the Overview is
  authoritative for exams, holidays and key dates; the course notes are
  authoritative for lecturers and totals.
- **Every Week 15 and Week 16 exam is provisional** — hatched, dashed border, a
  star, and a "subject to change" caveat — until the Examinations Section confirms
  the dates. Week 14 re-sits are shown as re-sits.
- Where the source doesn't print a value (a missing lecturer surname, the blank
  Orthodontics time label, the `-Wk. N` artefacts, `BSL` in a lecturer column) the
  calendar carries a blank plus an explanatory note rather than inventing anything.
- Totals: 409 class sessions + 1 quiz = 410, across 8 courses and 16 weeks;
  20 provisional exams, 8 re-sits, 4 public holidays, 2 no-class weeks.

## Requirements to rebuild

Julia 1.9+ **or** Python 3.9+ (standard library only — no packages). Rebuilding the
embedded font subset additionally needs `fonttools` + `brotli`, but the subset is
already committed in `src/font.css`, so a normal parser/inliner run needs nothing
extra.
